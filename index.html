可信机制

新闻可以被检查。

  • 每篇文章保留来源链接和首次发布时间。
  • 重要指标标注是否为实时、延迟或人工录入。
  • 读者可以通过 GitHub Issue 提交更正。
  • 所有页面结构和样式公开，可被复用和审计。
